# João Pedro — Portfólio

Portfólio profissional de **João Pedro**, Full Stack & Web Developer. Direção
visual editorial e monocromática, com animações discretas e foco em clareza,
performance e confiança.

**Repositório privado.** Este código-fonte não é open source, não está disponível
para download, fork, clonagem ou uso por terceiros.

## Stack

- **Next.js 16** (App Router) + **React 19**
- **TypeScript**
- **Tailwind CSS** + CSS variables
- **GSAP** + **ScrollTrigger**
- **Lenis** (smooth scrolling)
- **SplitType** (reveal de textos)
- **Framer Motion** (micro-interações)
- **Lucide React**
- **next/font** (Geist Sans, Geist Mono, Instrument Serif)
